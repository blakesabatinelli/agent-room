# Week 1 demo (Fri Oct 30) and decisions for the owner

## Demo, about 10 minutes

1. **Shell setting fix (0.1).** Phone: open the hub address, Rooms > Settings > Permissions; switch Shell on for an agent and the "Run shell commands without asking" setting appears nested under it. Mac: Permissions screen, same layout.
2. **Routing log (0.2, 0.5).** Run one real goal in the Room, then:
   `curl -s -H "Authorization: Bearer $TOKEN" http://127.0.0.1:4747/routing/export.jsonl | head -3 | jq .`
   Each line shows the candidates and their pick probabilities, the model that ran, tokens, cost, seconds, the outcome and the judge's score. Anything sent back carries a failure tag.
3. **Documents (0.4).** Ask an agent to "save a one-page brief to the Library". The file appears in `~/Agent Room/Library/general/<goal>/` with front matter; `GET /documents` lists it.
4. **File access spike (0.3).** `pnpm --filter @agent-room/hub exec tsx --test test/relay.test.ts` runs a cloud-style agent that reaches the hub only through the relay (now shelved, D9; the same MCP tools work over Tailscale), reads a granted file, proposes a write, and gets it applied after approval. Walk through `docs/spikes/0.3-file-access.md`.
