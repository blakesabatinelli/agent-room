# 3.1 Design refresh: Slack audit

Direction (PRODUCT.md section 8): light and calm, white canvas, pale sidebar, hairlines instead of boxes, one deep teal accent (#0B6E69), Avenir Next for names and headings, agents told apart by colour, avatar and persona, full dark mode with the same structure, native Mac feel. Nothing from Slack's visual identity.

This is what was found that looked like Slack, and what it is now. `packages/hub/test/design.test.ts` ("3.1 audit: no Slack names, colours or patterns in either app") keeps it from coming back.

## Judge lines

The judging lines an orchestrator writes (scores, "sent back because...") were already quiet messages, shown only in the work log. They stay in the Activity pane. The chat now shows one compact verdict chip under the last agent message of each task: Accepted, Sent back or Disputed (a jury split), the score, and one small chip per judge. Chips carry a glyph as well as a colour.

## Not borrowed

- Colour: one accent, teal. Warm and red tones are used only for state (waiting on you, unmet, sent back).
- Layout: no left rail of workspace icons, no threads pane, no channel browser. A goal card sits above the thread and the Command-K palette replaces the channel switcher.
- Icons: none from any set. Glyphs in chips are plain text characters.
- Words: no "channel", "workspace", "huddle".

## Reference caveat

The owner's "Drift and Anchor" brand work was named as a reference for fonts, colours and feel. Its files are not in this repository, so this pass follows PRODUCT.md section 8 only. If the brand has a palette or type that should win, change `light` and `dark` in `packages/app/src/palette.ts` and the three token blocks in `packages/hub/web/app.css`; `design.test.ts` checks the two stay in step and that contrast still passes.
