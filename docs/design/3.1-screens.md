# 3.1 Mac screens for the owner's sign-off

The phone web app was rendered here in Chromium, light and dark, at 390x844: `docs/screenshots/3.1-phone-*.png` (20 screens, two modes each). The Mac app is React Native macOS and cannot be rendered on this machine, and a react-native-web build would need the native shell, vibrancy and the menu stubbed out, so it would not show what the owner is signing off. Each Mac screen below needs a screenshot from a real Mac, in both modes (System Settings, Appearance, Light then Dark, or Settings in the app, Appearance).

How to capture: run the app against a hub with a goal in progress (a goal with a "Done means" list, one task sent back and one with a jury split), then take each screen with Shift-Command-4, Space, click the window.

Native pieces that were written without a Mac and have not been compiled: `packages/app/macos/AgentRoom-macOS/ARShell.m` (vibrancy view, Appearance override, the Go menu) and the one-line change to `AppDelegate.mm` (the window no longer forces light). If the Xcode build fails on ARShell.m, remove it from the AgentRoom-macOS target; the app falls back to the opaque pale sidebar and the in-window Command-K still works.
