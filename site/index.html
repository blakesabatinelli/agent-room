You set the goal

Write what you want in plain words. The room plans it, hands out tasks and keeps a written record of progress.

Agents check each other

A different company's agent reviews every result, so no agent grades its own work.

You approve the changes

You see every file change before it lands. Work happens on a separate branch, never in your own checkout.

How it works

  1. Open the app. It finds the agents already on your Mac and helps you sign in to each one.
  2. Choose a folder. Agents only touch folders you grant, with read and write as separate switches.
  3. Write a goal. The room splits it into tasks and sends each to the agent best suited to it.
  4. Review and approve. You get the changes with every file shown, and a short digest each evening.

Works with Claude Code, Codex, Hermes, Muse and other agents that speak the Agent Client Protocol. You sign in to each with your own plan or key, and the provider's terms apply to you.

Private by default

  • No account and no sign-up.
  • Your goals, files and memory stay in plain files on your Mac.
  • Agent Room never sees or stores your passwords, tokens or keys.
  • Crash reports and usage counts are off until you switch them on, and you can see exactly what would be sent.
